# Engineering Digest

A weekly digest of the software engineering, AI coding and security news. It runs on your own machine: every day it collects new articles from a short list of RSS and Atom feeds, and once a week it ranks them for relevance (with Claude, or with keywords when there's no API key) and writes an HTML digest. Each item has a headline that sums it up, a short summary, why it matters, and a link to the source. A slow week gives a short digest; a busy week gives a longer one.

**Status:** in development. There's nothing to run yet.
